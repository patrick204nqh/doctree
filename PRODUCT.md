# Product

## Register

product

## Users

One reader, working alone: an engineer who keeps a large local folder of task notes (Markdown task and journal files, drafts, JSON and text captures, Mermaid diagrams) and reads it many times a day, between other work. They know the folder layout. They are in a task, not browsing.

## Product Purpose

Doctree is a Chrome extension that opens a local folder and lets the reader move through it fast and read each file in place. It is read-only: it never edits, uploads or deletes. Success is that the reader gets from "I need that file" to reading it in a few keystrokes, and never thinks about the viewer itself.

## Brand Personality

Calm, precise, quiet. A tool that stays out of the way. It tells you where you are and shows files exactly as they are on disk (names with extensions, plain text unchanged), without decoration.

## Anti-references

- Notion or Obsidian chrome: icons, badges and widgets on everything, a decorated interface that competes with the content.

## Design Principles

1. **The tool disappears into the reading.** Content gets the width and the contrast. Chrome is minimal and can be hidden.
2. **Navigate by path, not by hunting.** A big folder is reached by keyboard first (quick open, index files, deep links), and the tree is the map, not the only road.
3. **Show what is on disk.** File and folder names appear whole, with extensions. Text and data files render unchanged.
4. **Accent marks where you are.** The accent colour is for the current file, its folders and state. Everything else stays neutral.
5. **Read-only and recoverable.** Nothing the viewer does can change the folder, and a wrong click is one Back away.

## Accessibility & Inclusion

WCAG AA contrast for text, including muted and placeholder text. Everything reachable and operable by keyboard with a visible focus ring. Respect `prefers-reduced-motion`. Light and dark themes, following the system until the reader chooses.
